# Student Grade Calculator

## Project Description
The Student Grade Calculator is a Python-based project
that calculates a student's grade based on their marks.
It displays the student's name, marks, grade, remark,
and pass or fail result.

## Features
- Accepts the student's name and marks.
- Validates marks between 0 and 100.
- Calculates grades using conditional statements.
- Displays remarks based on performance.
- Shows the final PASS or FAIL result.

## Technologies Used
- Python
- Jupyter Notebook
- VS Code

## Grade Criteria
- 90–100: A+ - Excellent!
- 80–89: A - Very Good!
- 70–79: B - Good!
- 60–69: C - Satisfactory!
- 50–59: D - Needs Improvement!
- 35–49: E - Work Hard!
- 0–34: F - Keep Practicing!

## How to Run
1. Open the Student_Grade_Calculator.ipynb file.
2. Run the Python code in Jupyter Notebook.
3. Enter the student's name.
4. Enter marks between 0 and 100.
5. View the generated student report.
